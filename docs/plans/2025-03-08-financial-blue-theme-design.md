# 财经蓝主题设计文档

**日期：** 2025-03-08
**主题名称：** 财经蓝（Financial Blue）
**主题分类：** 简约（Minimal）

## 概述

为写作助手添加一款适合财经类文章的专业主题，采用经典蓝色系搭配金色点缀，简约大气，并支持暗黑模式自动切换。

## 设计目标

1. **专业可信赖** - 深蓝色系传达金融行业的专业感
2. **简约大气** - 避免过度装饰，让内容成为焦点
3. **重点突出** - 通过金色强调关键数据和重要观点
4. **暗黑模式** - 使用 CSS media query 自动适配系统设置

## 组件设计

### 标题系统

- **H1（文章标题）**
  - 居中对齐，底部金色边框（2px）
  - 亮色：深蓝文字 + 金色下划线
  - 暗色：浅蓝文字 + 金色下划线
  - 字号：1.75em，字重：600

- **H2（主要章节）**
  - 左侧金色竖线（4px）+ 深蓝/浅蓝文字
  - 内边距：2px 12px
  - 字号：1.35em，字重：600

- **H3-H6（子标题）**
  - 渐变灰度，逐级变淡
  - H3：主色调
  - H4-H6：次要文字颜色
  - 字重逐级递减（600 → 500）

### 引用块（重点设计）

财经文章需要强调关键数据和观点，引用块采用精心设计：

- **普通引用**
  - 左侧 4px 金色粗边框
  - 亮色：浅蓝背景 `#eff6ff`
  - 暗色：深蓝背景 `#1e3a5f`
  - 内边距：12px 20px
  - 字号：0.95em

- **嵌套引用**
  - 使用蓝色细边框（3px）
  - 保持层级清晰

### 强调元素

- **加粗文本**
  - 金色（`#d4a855` / `#fbbf24`）
  - 字重：600
  - 突出重要数据和结论

- **链接**
  - 金色文字 + 下划线
  - 悬停时加深颜色
  - 下划线偏移 4px，厚度 1px

- **高亮标记（mark）**
  - 金色半透明背景
  - 亮色：`rgba(212, 168, 85, 0.2)`
  - 暗色：`rgba(251, 191, 36, 0.2)`

### 表格样式

- **表头**
  - 深蓝/亮蓝背景
  - 白色/浅色文字，居中对齐
  - 字重：600
  - 金色分隔线

- **表格行**
  - 亮色：白色背景，偶数行浅灰
  - 暗色：深蓝背景，偶数行深蓝灰
  - 1px 边框分隔

- **数字列**
  - 右对齐（金融标准）
  - 使用等宽字体

### 其他元素

- **列表**：深蓝/亮蓝序号和标记，嵌套时渐变
- **分割线**：金色细线（1px）
- **代码块**：浅灰背景 + 蓝色文字
- **警告框**：蓝色系配色，适配原有结构

## 技术实现

### 文件结构

```
src/themes/financial-blue.css    # 财经蓝主题 CSS 文件
```

### CSS 架构

使用 CSS 变量实现双主题：

```css
/* CSS 变量定义 - 亮色模式（默认） */
#writing-assistant {
  --primary: #1e40af;
  --accent: #d4a855;
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --text-primary: #1f2937;
  --text-secondary: #6b7280;
  --border: #e5e7eb;
  --quote-bg: #eff6ff;
  /* ... */
}

/* 暗黑模式覆盖 */
@media (prefers-color-scheme: dark) {
  #writing-assistant {
    --primary: #60a5fa;
    --accent: #fbbf24;
    --bg-primary: #0f172a;
    --bg-secondary: #1e293b;
    --text-primary: #f1f5f9;
    --text-secondary: #94a3b8;
    --border: #334155;
    --quote-bg: #1e3a5f;
    /* ... */
  }
}

/* 组件样式使用 CSS 变量 */
#writing-assistant h2 {
  color: var(--primary);
  border-left: 3px solid var(--accent);
}
```

## 实现要点

1. **CSS 变量** - 所有颜色通过变量引用，便于维护和调整
2. **Media Query** - 使用 `@media (prefers-color-scheme: dark)` 实现自动切换
3. **一致性** - 保持与现有主题相同的 CSS 结构和选择器
4. **可读性** - 确保所有元素在两种模式下对比度充足
5. **性能** - CSS 文件大小控制在合理范围
